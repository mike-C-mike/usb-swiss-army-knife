# Simple Workflow

1. Launch `UsbSwissArmyKnife.exe`.
2. Resume a saved session or start a guided build.
3. Choose interaction level: Full Guided, Intermediate, or Custom.
4. Choose purpose: IT Support, DFIR, or OSINT.
5. Choose package level: Minimal, Solid, or Overkill.
6. Review the generated USB build path and suggested drive sizes.
7. Enter drive letters to exclude from selection. C is excluded by default.
8. Select the target drive or enter a manual path.
9. Confirm writing folders/templates.
10. Continue to the next sized/role drive or stop and resume later.
