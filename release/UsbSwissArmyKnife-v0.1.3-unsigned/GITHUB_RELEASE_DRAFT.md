# USB Swiss Army Knife v0.1.3 Unsigned Pre-Release

This release introduces guided USB build paths.

## Highlights

- Saved session resume.
- Full Guided, Intermediate, and Custom modes.
- IT Support, DFIR, and OSINT purposes.
- Minimal, Solid, and Overkill package levels.

- Drive exclusion list.
- Multi-drive build flow.

This project does not download, bundle, or redistribute third-party tools or payloads. It creates folders and documentation templates only.
