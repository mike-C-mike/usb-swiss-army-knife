# Release Checklist

- [ ] Build on Windows using `build_release.ps1`.
- [ ] Launch `UsbSwissArmyKnife.exe`.
- [ ] Confirm startup shows Resume when a saved session exists.
- [ ] Run Full Guided -> DFIR -> Solid.
- [ ] Confirm generated drive roles appear.
- [ ] Confirm C is excluded by default.
- [ ] Write to a temporary test folder or test USB.
- [ ] Confirm README, manifests, attribution, source verification, and build plan files are created.
- [ ] Confirm release ZIP and checksum files are created.
- [ ] Upload release ZIP and checksum to GitHub pre-release.
