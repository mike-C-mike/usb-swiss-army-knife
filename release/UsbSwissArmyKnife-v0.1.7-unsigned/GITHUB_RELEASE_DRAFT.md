# USB Swiss Army Knife v0.1.7 Unsigned Pre-Release

## Release type

Unsigned Windows pre-release.

## Summary

This release fixes XLSX workbook generation and moves planning/session output to a visible user-profile folder:

```text
%USERPROFILE%\UsbSwissArmyKnife\planning
```

The EXE launches a console-based guided USB toolkit builder. It creates folder structures, editable CSV/XLSX planning files, source verification templates, attribution records, and build documentation.

## Boundary

This tool does not download, install, bundle, format, erase, or redistribute third-party tools. Users populate their toolkit locally from official publisher-controlled sources.
