# USB Swiss Army Knife v0.1.2 Unsigned Pre-Release

USB Swiss Army Knife v0.1.2 is an unsigned console EXE pre-release for building local USB toolkit folder structures.

## Highlights

- Selectable build plans: DFIR, IT Support, and OSINT.
- Plan-specific folders and templates.
- No manual hash-generator menu options.
- Source verification records for official URLs and source-published hashes.
- Does not redistribute third-party tools, installers, ISOs, archives, wordlists, VM images, vendor payloads, or downloaded content.
