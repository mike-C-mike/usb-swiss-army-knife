# Known Limitations

- Windows-focused console EXE launcher.
- No GUI yet.
- Does not download or install third-party tools.
- Does not include third-party binaries, installers, ISOs, archives, wordlists, VM images, or vendor payloads.
- Does not validate third-party tools.
- Does not perform forensic evidence hashing.
- Manual hash-generator options were removed in v0.1.2. Future source-verification features may generate a local tool hash list after a USB build is populated.
