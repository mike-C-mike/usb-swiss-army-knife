# Simple Workflow

1. Run `UsbSwissArmyKnife.exe`.
2. Select or change the toolkit root.
3. Select the build plan: DFIR, IT Support, or OSINT.
4. Review the folder plan.
5. Create/update selected build plan folders and templates.
6. Populate the toolkit locally from official publisher-controlled sources.
7. Add tool manifest, attribution, and source-verification records.
8. Build a file inventory or status report as needed.

This utility does not download, bundle, validate, or recommend third-party tools.
