# Release Checklist

- [ ] Build on Windows with `build_release.ps1`.
- [ ] Run the generated EXE.
- [ ] Create a test folder layout on a disposable/test USB path.
- [ ] Test Explorer, CMD, and PowerShell launch actions.
- [ ] Add a sample manifest entry.
- [ ] Add a sample attribution entry.
- [ ] Hash one file.
- [ ] Hash a small test folder recursively.
- [ ] Build file inventory CSV.
- [ ] Write toolkit status report.
- [ ] Confirm no third-party binaries are included.
- [ ] Confirm ZIP and EXE hashes are generated.
- [ ] Upload ZIP and checksum files to GitHub pre-release.
