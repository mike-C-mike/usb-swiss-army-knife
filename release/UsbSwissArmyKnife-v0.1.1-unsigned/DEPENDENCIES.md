# Dependencies

## Runtime

- Python standard library only before packaging.
- Windows PowerShell is used on the target Windows machine.

## Build

- PyInstaller. PyInstaller is GPL 2.0 with a bootloader exception that allows commercial and closed-source distribution of applications built with it.

## Redistribution boundary

This project must not redistribute third-party binaries, installers, ISOs, archives, wordlists, VM images, vendor tools, or downloaded project content.
