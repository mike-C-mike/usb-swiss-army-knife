# USB Swiss Army Knife v0.1.1 Unsigned Pre-Release

USB Swiss Army Knife is a console utility that opens from an EXE and creates/maintains a structured USB/field-toolkit layout.

## Assets

Upload from the `release` folder after running `build_release.ps1`:

- `UsbSwissArmyKnife-v0.1.1-unsigned.zip`
- `UsbSwissArmyKnife-v0.1.1-unsigned-SHA256SUMS.txt`
- `UsbSwissArmyKnife-v0.1.1-unsigned.zip.sha256.txt`

## Important boundary

This release does not include third-party tools, vendor binaries, installers, ISOs, archives, wordlists, VM images, or downloaded project content. Users populate the toolkit locally from official sources.
