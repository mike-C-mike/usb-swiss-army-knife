# USB Profiles

Profiles map functional roles to repository folders and minimum media sizes.

Current concepts include:

- Network troubleshooting
- Help desk
- Forensic acquisition
- Endpoint recovery
- Ventoy boot and rescue
- Authorized pentest lab
- OSINT reference toolkit
- Full portable toolkit
- Master repository mirror

Profile minimum sizes are safeguards, not guarantees. Actual size is calculated before provisioning.
