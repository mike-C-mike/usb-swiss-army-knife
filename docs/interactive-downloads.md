# Interactive Downloads

Some publishers require a form, account, email link, or EULA.

For these tools the builder:

1. Opens the official page.
2. Displays the required user steps.
3. Watches the user’s Downloads folder.
4. Detects the expected completed package.
5. Checks signatures where configured.
6. Copies it into the local repository.
7. Hashes and inventories it.

The builder does not bypass publisher controls or accept legal terms on the user’s behalf.
