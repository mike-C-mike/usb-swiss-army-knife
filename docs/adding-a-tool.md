# Adding a Tool

Before adding a tool:

1. Confirm the source is controlled by the upstream publisher.
2. Review the current license or vendor terms.
3. Decide whether the item can be downloaded automatically.
4. Determine whether it is portable, requires elevation, installs a driver, or modifies a live system.
5. Record appropriate attribution.
6. Add it only to profiles where it has a clear purpose.
7. Test initial download, update detection, audit, and provisioning.
8. Confirm no downloaded artifact is committed.
