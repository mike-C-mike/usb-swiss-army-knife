# Legal and Licensing Model

USB Swiss Army Knife distributes no third-party software or content.

The repository’s MIT license covers only its original automation, configuration structure, documentation, and interface logic.

Downloaded material remains subject to upstream terms.

The safest release model is source-only:

- No preloaded USB images
- No bundled tool archives
- No mirrored repositories
- No vendor packages
- No wordlists
- No VM images

This document is general project guidance and not legal advice.
