# Catalog Schema

Each catalog entry should document:

- Stable project identifier
- Display name
- Category
- Destination folder
- Source type
- Official source
- Allowed hosts
- Release or asset selection policy
- Extraction behavior
- Signature policy
- Installation policy
- Resource-bundle membership
- Usage and modification warnings
- Attribution metadata

Supported source patterns currently include direct HTTPS downloads, official GitHub releases, official GitHub branch archives, and browser-assisted interactive imports.
