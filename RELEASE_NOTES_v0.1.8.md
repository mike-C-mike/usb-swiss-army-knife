# USB Swiss Army Knife v0.1.8 - Expanded Source-of-Truth Tool List

## Release type

Unsigned Windows pre-release build kit.

## What changed

- Expands the built-in software catalog across IT Support, DFIR, OSINT, and Everything builds.
- Renames the editable software inclusion file to `ToolList_SOURCE_OF_TRUTH.csv`.
- Keeps `Include` as the intended Yes/No control for excluding software records without deleting rows.
- Keeps FolderStructure.csv and the XLSX workbook as planning/informational outputs.
- Confirms the USB write workflow reads the current source-of-truth CSV before writing tool source cards to the selected drive.
- Preserves the project boundary: no third-party tools, installers, ISOs, VM images, archives, wordlists, or downloaded content are bundled or redistributed.

## Notes

Tool names and source URLs are planning records and common examples only. They are not endorsements, recommendations, license determinations, validation statements, or a substitute for agency policy. Users must download tools themselves from official publisher-controlled sources and verify license/source/hash information where available.
