# Upstream Projects

## Gratitude

USB Swiss Army Knife would provide no meaningful capability without the people and organizations who create, maintain, document, test, and support the projects in its catalog.

The builder’s role is organizational. The technical achievements belong to the upstream maintainers.

This page intentionally gives visible credit rather than treating attribution as a legal footnote.

---

## Microsoft Sysinternals

Microsoft Sysinternals has provided generations of Windows administrators, responders, investigators, and developers with exceptionally capable diagnostic utilities.

USB Swiss Army Knife retrieves the official Sysinternals Suite and organizes it as a portable help-desk and Windows-triage resource.

**Credit:** Microsoft and the Sysinternals maintainers  
**Official source:** Microsoft Sysinternals  
**Redistributed here:** No

## Rufus

Rufus is one of the most dependable tools available for creating bootable USB media. Its small, portable executable has made operating-system installation and recovery media dramatically easier for countless users.

USB Swiss Army Knife retrieves Rufus from its official release source and uses it as an optional boot-media preparation utility.

**Credit:** Pete Batard and contributors  
**Redistributed here:** No

## Ventoy

Ventoy changed multiboot USB preparation by allowing users to place supported images directly on a data partition rather than repeatedly reformatting media.

USB Swiss Army Knife organizes boot-image folders and retrieves Ventoy from its official project releases.

**Credit:** The Ventoy maintainers and contributors  
**Redistributed here:** No

## Wireshark and Npcap

Wireshark is an indispensable packet-analysis platform used across networking, incident response, education, troubleshooting, and security research. Npcap enables live packet capture on supported Windows systems.

USB Swiss Army Knife retrieves the official portable Wireshark package and treats Npcap separately because installing a capture driver modifies the local system.

**Credit:** The Wireshark Foundation, contributors, and the Npcap/Nmap maintainers  
**Redistributed here:** No

## Magnet Forensics

Magnet Forensics provides valuable free acquisition and response utilities to the forensic community, including DumpIt and Magnet Acquire.

USB Swiss Army Knife does not bypass vendor forms or license acceptance. It opens the official page, guides the user through the required interaction, and imports the user’s downloaded package into their local toolkit.

**Credit:** Magnet Forensics and its development teams  
**Redistributed here:** No

## Belkasoft

Belkasoft Live RAM Capturer gives investigators and responders an accessible memory-acquisition option.

USB Swiss Army Knife routes users through Belkasoft’s official download process and does not redistribute the package.

**Credit:** Belkasoft and its development teams  
**Redistributed here:** No

## WinPmem

WinPmem represents important open-source work in Windows physical-memory acquisition.

USB Swiss Army Knife retrieves an approved signed production release from the official upstream repository rather than blindly selecting an unsuitable test build.

**Credit:** The WinPmem and Velocidex maintainers  
**Redistributed here:** No

## Exterro FTK Imager

FTK Imager is a widely recognized forensic acquisition and preview utility that has served investigators, laboratories, students, and practitioners for many years.

USB Swiss Army Knife sends users through Exterro’s official download process and organizes the resulting user-acquired package.

**Credit:** Exterro, AccessData’s historical contributors, and the FTK Imager development teams  
**Redistributed here:** No

## TestDisk and PhotoRec

TestDisk and PhotoRec have helped users recover partitions and files across a remarkable range of systems and storage failures.

USB Swiss Army Knife retrieves the official portable package and keeps recovery capability available without requiring installation.

**Credit:** Christophe Grenier and contributors  
**Redistributed here:** No

## CyberChef

CyberChef is one of the most versatile client-side data-transformation tools available. It gives analysts a visual workbench for encoding, decoding, hashing, parsing, decompression, conversion, and countless other operations.

USB Swiss Army Knife retrieves the official standalone release so users can run it locally.

**Credit:** GCHQ and the CyberChef maintainers and contributors  
**Redistributed here:** No

## GTFOBins

GTFOBins documents legitimate Unix and Linux binaries that can exhibit security-relevant behaviors in particular contexts. It is valuable for assessment, defensive understanding, detection engineering, and privilege-escalation education.

USB Swiss Army Knife downloads the official upstream source archive for local reference.

**Credit:** The GTFOBins maintainers and contributors  
**Redistributed here:** No

## LOLBAS

LOLBAS documents Microsoft-signed binaries, scripts, and libraries that can be used in unexpected ways. It is an important resource for defenders, investigators, hunters, and authorized assessors.

USB Swiss Army Knife retrieves the official repository for local reference.

**Credit:** The LOLBAS Project maintainers and contributors  
**Redistributed here:** No

## OWASP Cheat Sheet Series

The OWASP Cheat Sheet Series translates application-security principles into practical implementation guidance.

USB Swiss Army Knife retrieves the official source repository and links users back to the current rendered project.

**Credit:** OWASP Foundation, Cheat Sheet Series maintainers, authors, and reviewers  
**Redistributed here:** No

## SecLists

SecLists is an extraordinary community collection of discovery, username, password, fuzzing, and assessment lists. It saves practitioners enormous time and supports repeatable testing.

Because some content may trigger endpoint protection, USB Swiss Army Knife keeps SecLists optional and requires deliberate user selection.

**Credit:** Daniel Miessler, maintainers, contributors, and source-list authors  
**Redistributed here:** No

USB Swiss Army Knife includes it only in an explicitly selected advanced reference bundle.

**Credit:** Swissky, maintainers, and contributors  
**Redistributed here:** No

USB Swiss Army Knife retrieves the official source repository as an optional reference.

## Supporting upstream work

Users should support upstream projects by:

- Reading and respecting their documentation and licenses
- Reporting reproducible issues to the correct project
- Contributing fixes or documentation
- Sponsoring or donating where an official option exists
- Crediting the project in training, reporting, and published work
- Avoiding unofficial mirrors when an authentic source is available
