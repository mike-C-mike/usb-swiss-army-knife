# USB Swiss Army Knife v0.2.9 Unsigned Pre-Release

This release adds an automatically generated `OnlineResources.html` dashboard built from `ToolList_SOURCE_OF_TRUTH.csv`.

## Highlights

- Clickable HTML resource page for official source pages, exact direct download URLs, and hash source pages.
- CSV remains the only software source of truth.
- Advanced menu and Download Manager shortcuts to open the resource page.
- Toolkit writes copy the HTML page into `_toolkit_admin/planning/` when available.
- No third-party binaries are shipped in the repository.
- No installer execution, drive formatting, drive erasing, or tool endorsement.
